SamCalculator

A simple and flexible Windows calculator with Samsung One UI design and functionality.

Features:
* One UI Style: Clean design inspired by Samsung One UI.
* Unit Converter: Built in converter for different units and measurements.
* Calculation History with Notes: Save your history and add custom notes to each calculation to keep track of your results.
* Responsive Layout: Works smoothly in both portrait and landscape modes with a fully resizable window.
* Deep Customization: Adjust colors, interface transparency, or set your own background image.

Download & Installation:
1. Open the Releases section.
2. Download SamCalculator_Setup.exe.
3. Run the setup and follow the instructions.
